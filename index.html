Four ways to use a server

Most MCP debugging is guessing. Patchbay puts every tool, argument and raw message in front of you.

Inspect

Connect a server and see every tool, resource and prompt with its full schema.

Call

Forms are built from each tool's JSON schema. Fill one in, fire it, read the exact response.

Chain

Pipe one tool's output into the next. Save the chain and replay it whenever the server changes.

Agent

Give Claude every patched tool and a goal. Each call lights up the cable it travels on.
